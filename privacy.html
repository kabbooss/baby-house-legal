Kabbo's Lab Pipeline

Privacy Policy

Effective date: 27 October 2026

1. Who this policy covers

Kabbo's Lab Pipeline ("the tool") is a personal, non-commercial automation project operated by the owner of the Kabbo's Lab YouTube channel. The tool has one user: the channel owner. It is not offered as a public service and does not create user accounts.

2. Information the tool accesses

With the channel owner's permission, the tool uses Google OAuth to request the youtube.upload scope. This allows it to upload videos to the owner's own YouTube channel and to set video metadata such as the title, description, tags, thumbnail, and scheduled publish time.

The tool does not request access to viewers' data, channel analytics, comments, subscribers, private messages, or any other Google account data.

3. How information is used

The upload permission is used solely to publish the owner's educational videos. Scripts, narration, images, and rendered video files are processed on the owner's computer and on private GitHub Actions runners, then uploaded to YouTube.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

4. Storage and sharing

  • OAuth client credentials and refresh tokens are stored as encrypted GitHub Actions secrets and in a local, git-ignored file.
  • Video files and intermediate assets are kept only as long as needed to produce and upload a video.
  • No Google user data is sold, rented, or shared with third parties.
  • No advertising, tracking pixels, or analytics scripts are used on this website.

5. Retention and deletion

The tool keeps only the credentials needed to upload videos. The channel owner can revoke access at any time from Google Account permissions. Revoking access immediately invalidates the stored refresh token.

6. This website

This website is a static information page hosted by GitHub Pages. It does not set cookies, run analytics, or collect personal information. GitHub may process standard server logs as described in the GitHub Privacy Statement.
