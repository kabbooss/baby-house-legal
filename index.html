Personal automation project

Kabbo's Lab Pipeline

A personal, non-commercial tool that helps produce short educational videos in Bangla and English for the Kabbo's Lab YouTube channel.

What it does

The pipeline researches a topic, drafts a script with an AI language model, generates narration, selects openly licensed illustrations, renders the video, and uploads the finished file to the operator's own YouTube channel through the YouTube Data API.

It is a single-user project. It does not create accounts for the public, does not collect viewer information, and does not run a service on behalf of other people.

Google API use

The tool requests only the youtube.upload permission. That permission is used to upload the operator's own videos and to set their title, description, tags, thumbnail, and scheduled publish time.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
