# Kabbo's Lab legal pages

Static homepage, privacy policy, and terms for the personal **Kabbo's Lab
Pipeline** automation tool used by the Kabbo's Lab YouTube channel.

Published with GitHub Pages:

- https://kabbooss.github.io/baby-house-legal/
- https://kabbooss.github.io/baby-house-legal/privacy.html
- https://kabbooss.github.io/baby-house-legal/terms.html

These pages exist to satisfy Google OAuth branding requirements for the
single-user upload tool. No secrets or analytics are stored here.
